# Images

`profile.jpg` is the photo shown on the homepage. To change it, replace that
file (keep the name exactly `profile.jpg`, lowercase).

- Portrait orientation works best; roughly 4:5 (e.g. 800×1000 px) is ideal.
- Keep it under ~500 KB so the page loads quickly.

If the file is missing, the homepage falls back to a dashed placeholder box
rather than showing a broken image.
